<RequestExample>

```bash cURL
curl --fail-with-body "https://api.browserbunny.dev/v1/environments" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY"
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    catalog = client.environments.list()
    print(catalog)
```

```javascript JavaScript
const response = await fetch("https://api.browserbunny.dev/v1/environments", {
  headers: {
    Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}`
  }
});
const catalog = await response.json();
if (!response.ok) throw new Error(JSON.stringify(catalog));
console.log(catalog);
```
