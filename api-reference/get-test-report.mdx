---
title: "Get a test report"
openapi: "/openapi/public-v1.json GET /v1/tests/{test_id}/report"
---

Read structured findings and Markdown for a bug handoff. Optionally pass
`execution_id` to include one execution. See [copy a bug report](/results#copy-a-bug-report)
for the workflow.

<RequestExample>

```bash cURL
curl --fail-with-body "https://api.browserbunny.dev/v1/tests/TEST_ID/report" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY"
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    report = client.tests.report("TEST_ID")
    print(report)
```

```javascript JavaScript
const response = await fetch("https://api.browserbunny.dev/v1/tests/TEST_ID/report", {
  headers: {
    Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}`
  }
});
const report = await response.json();
if (!response.ok) throw new Error(JSON.stringify(report));
console.log(report);
```

</RequestExample>
