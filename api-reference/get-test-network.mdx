title: "Get execution network requests"
openapi: "/openapi/public-v1.json GET /v1/tests/{test_id}/executions/{execution_id}/network"
---

<RequestExample>

```bash cURL
curl --fail-with-body \
  "https://api.browserbunny.dev/v1/tests/TEST_ID/executions/EXECUTION_ID/network?limit=200" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY"
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    page = client.tests.network("TEST_ID", "EXECUTION_ID", limit=200)
    print(page)
```

```javascript JavaScript
const response = await fetch(
  "https://api.browserbunny.dev/v1/tests/TEST_ID/executions/EXECUTION_ID/network?limit=200",
  { headers: { Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}` } }
);
const page = await response.json();
if (!response.ok) throw new Error(JSON.stringify(page));
console.log(page);
```
