---
title: "Inspect network activity"
description: "Find failed requests and review request timings for an execution."
---

Use an execution's `network_url`, or the IDs from [Get a test](/api-reference/get-test), to read its network requests.

## Find failed requests

Set `errors_only=true` to return HTTP errors and transport failures. Omit it to
include all requests. Connected agents use `get_test_network` with the same inputs.

<CodeGroup>

```bash cURL
curl --fail-with-body \
  "https://api.browserbunny.dev/v1/tests/TEST_ID/executions/EXECUTION_ID/network?errors_only=true&limit=200" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY"
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    page = client.tests.network("TEST_ID", "EXECUTION_ID", errors_only=True, limit=200)
    print(page)
```

```javascript JavaScript
const response = await fetch(
  "https://api.browserbunny.dev/v1/tests/TEST_ID/executions/EXECUTION_ID/network?errors_only=true&limit=200",
  { headers: { Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}` } }
);
const page = await response.json();
if (!response.ok) throw new Error(JSON.stringify(page));
console.log(page);
```

</CodeGroup>

## Read the response

```json
{
  "status": "partial",
  "expires_at": "2026-10-10T12:00:00Z",
  "data": [{
    "id": "net_1",
    "method": "POST",
    "endpoint_id": "endpoint_0123456789abcdef01234567",
    "status": "failed",
    "status_code": 503,
    "started_at": "2026-09-26T12:00:00Z",
    "duration_ms": 842
  }],
  "next_cursor": null
}
```

| Response status | Meaning |
| --- | --- |
| `collecting` | Requests are still being collected. |
| `complete` | Collection finished with no reported gaps. |
| `partial` | Some requests or details may be missing. |
| `unavailable` | Network information is unavailable. |
| `expired` | The retention period ended. |

| Request status | Meaning |
| --- | --- |
| `succeeded` | Completed with an HTTP status below 400. |
| `failed` | An HTTP error or transport failure occurred. |
| `cancelled` | The request was cancelled. |
| `unfinished` | No result was observed before collection ended. |
| `unknown` | There is insufficient information to determine a result. |

- **Missing values:** `null` means unavailable, not zero. An empty partial response does not prove that no requests failed.
- **Test result:** an HTTP error does not automatically fail the test. Your requested checks determine the result.
- **Pagination:** pass `next_cursor` as `cursor` until it is `null`. Keep `errors_only` unchanged. `limit` defaults to 200 and accepts up to 500.
- **Refresh:** start again without a cursor to see newly collected requests.
- **Privacy:** endpoint IDs identify requests without exposing raw URLs. Request/response bodies and credentials are excluded. Network information expires after 14 days.
