## Select devices with the latest browser

Use `devices` for a simple list of targets. Each name creates one execution using
the latest browser release available from AWS. AWS manages the Windows version.

| Device name | Target |
| --- | --- |
| `desktop-chrome` | Windows desktop with Chrome |
| `desktop-edge` | Windows desktop with Edge |
| `desktop-firefox` | Windows desktop with Firefox |

<CodeGroup>

```bash cURL
curl --fail-with-body "https://api.browserbunny.dev/v1/tests" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "start_url": "https://example.com",
    "instructions": "Verify that the page heading is Example Domain.",
    "devices": ["desktop-chrome", "desktop-firefox"]
  }'
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    test = client.tests.create(
        start_url="https://example.com",
        instructions="Verify that the page heading is Example Domain.",
        devices=["desktop-chrome", "desktop-firefox"],
    )
    print(test)
```

```javascript JavaScript
const response = await fetch("https://api.browserbunny.dev/v1/tests", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    start_url: "https://example.com",
    instructions: "Verify that the page heading is Example Domain.",
    devices: ["desktop-chrome", "desktop-firefox"]
  })
});
const test = await response.json();
if (!response.ok) throw new Error(JSON.stringify(test));
console.log(test);
```

</CodeGroup>

- **Use distinct names:** `devices` must be a nonempty list without duplicates.
- **Use the default:** omit `devices` for one Windows Chrome `latest` execution.

## Discover capabilities

<CodeGroup>

```bash cURL
curl --fail-with-body "https://api.browserbunny.dev/v1/devices" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY"
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    catalog = client.devices.list()
    print(catalog)
```

```javascript JavaScript
const response = await fetch("https://api.browserbunny.dev/v1/devices", {
  headers: {
    Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}`
  }
});
const catalog = await response.json();
if (!response.ok) throw new Error(JSON.stringify(catalog));
console.log(catalog);
```

</CodeGroup>

### Read the catalog

| Response field | Meaning |
| --- | --- |
| `default` | Device names used when you omit `devices` |
| `data[].name` | Accepted name to pass in `devices` |
| `data[].os` | Operating system |
| `data[].browser` | Browser used for this device |
| `data[].capabilities` | Upload, network capture, and condition support |

Pass names from `data` directly in your request. The service selects the latest
browser release AWS offers and releases each browser when execution finishes.
Results include the resolved configuration and observed software versions.

### Check supported features

- **File uploads:** read `capabilities.file_upload` for file-input upload support.
- **Network requests:** `capabilities.network_capture` is `true` when network
  information is available. See [network activity](/network) for request details.
- **Conditions:** read `capabilities.conditions` for support, deployment enablement,
  and any unavailable reason.

Network, locale, and timezone conditions currently require **Chrome** and must be
verified in each session. See [conditions](/conditions) before selecting multiple browsers.
