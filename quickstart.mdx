## Before you start

1. Create a project API key in the [dashboard](https://dash.browserbunny.dev).
2. Make sure your account has test minutes.
3. Complete [API client setup](/client-setup/humans) for your chosen language.
4. Set your project key:

```bash
export BROWSERBUNNY_API_KEY="YOUR_PROJECT_API_KEY"
```

## Create a test

| Input | What to provide |
| --- | --- |
| `start_url` | The public HTTPS page where the test starts |
| `instructions` | What to do and what to verify |

Omit `environments` to use Windows desktop Chrome with the latest release
available from AWS.

<CodeGroup>

```bash cURL
curl --fail-with-body "https://api.browserbunny.dev/v1/tests" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: first-homepage-test-001" \
  --data '{
  "start_url": "https://example.com",
  "instructions": "Verify that the page heading is Example Domain."
}'
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    test = client.tests.create(
        start_url='https://example.com',
        instructions='Verify that the page heading is Example Domain.',
        idempotency_key="first-homepage-test-001",
    )
    print(test)
```

```javascript JavaScript
const response = await fetch("https://api.browserbunny.dev/v1/tests", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}`,
    "Content-Type": "application/json",
    "Idempotency-Key": "first-homepage-test-001"
  },
  body: JSON.stringify({
    "start_url": "https://example.com",
    "instructions": "Verify that the page heading is Example Domain."
  })
});
const test = await response.json();
if (!response.ok) throw new Error(JSON.stringify(test));
console.log(test);
```

</CodeGroup>

### Read the response

- **Accepted:** HTTP `202` means the test is ready for preparation.
- **Test ID:** save the returned `id`, which starts with `test_`.
- **Executions:** `executions` contains one entry per selected environment.

**Acceptance is asynchronous.** The browser work finishes later. Unsupported
instructions can produce an execution error before a browser is allocated.

### Retry safely

Keep the same `Idempotency-Key` and request body if the response is lost.

| Retry | Response |
| --- | --- |
| Same key and input | HTTP `200` with the existing test |
| Same key with changed input | HTTP `409` |

## Follow the test

Replace `TEST_ID` with the returned ID:

<CodeGroup>

```bash cURL
curl --fail-with-body "https://api.browserbunny.dev/v1/tests/TEST_ID" \
  -H "Authorization: Bearer $BROWSERBUNNY_API_KEY"
```

```python Python
from browserbunny import BrowserBunny

with BrowserBunny() as client:
    test = client.tests.get("TEST_ID")
    print(test)
```

```javascript JavaScript
const response = await fetch("https://api.browserbunny.dev/v1/tests/TEST_ID", {
  headers: {
    Authorization: `Bearer ${process.env.BROWSERBUNNY_API_KEY}`
  }
});
const test = await response.json();
if (!response.ok) throw new Error(JSON.stringify(test));
console.log(test);
```

</CodeGroup>

Repeat this request about every two seconds until `status` is terminal.

### While the test is active

| Status | Meaning |
| --- | --- |
| `queued` | Waiting to start |
| `running` | Executing the test |
| `cancelling` | Finishing cancellation and cleanup |

### When the test is finished

Stop polling when `status` is one of these terminal values:

| Status | Meaning |
| --- | --- |
| `passed` | Requested checks passed |
| `failed` | A requested check failed |
| `inconclusive` | Available evidence could not establish the result |
| `error` | Preparation or execution could not complete |
| `cancelled` | The test was cancelled |

### Inspect the result

- **Completion count:** `execution_counts.finished` tells you how many executions
  have finished.
- **Dashboard:** open the returned `url` while signed in.
- **Per-environment evidence:** inspect each execution's `checks`, `session_url`,
  and `error`.

For field details and mixed results, see [results, logs, and usage](/results).
