## What you need

| Task | Requirement |
| --- | --- |
| Connect to the documentation MCP | An MCP-compatible client; no API key required |
| Create browser tests | A project API key and available test minutes |
| Review tests in the dashboard | Sign-in to the owning account |

Both paths use the same test API, environments, and results.
