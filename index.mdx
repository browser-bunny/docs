## From instructions to evidence

<Steps>
  <Step title="Describe what to do and verify">
    - Provide a public HTTPS starting URL.
    - Describe the actions and expected result.
    - Include supported conditions such as a 3G connection or Spanish browser language.
  </Step>
  <Step title="Choose the browsers">
    - Use Windows Chrome by default, or select Chrome, Firefox, and Edge.
    - Each environment gets one execution of the same instructions.
  </Step>
  <Step title="Read the result">
    - Follow the test until it finishes.
    - Inspect each execution's status and checks.
    - Open session evidence to review what happened.
  </Step>
</Steps>
